AnyHomes

Premium & High-End Home Management System for modern Minecraft servers.

Plugin Overview

AnyHomes is an advanced, high-performance home teleporter and management plugin designed specifically for Paper, Purpur, and modern Minecraft server forks. Engineered with completely asynchronous database connections (SQLite & MySQL support), a YAML-driven GUI menu editor, and native LuckPerms support, it provides a seamless user experience while guaranteeing peak server performance.

Async Processing

Uses HikariCP pool database and Paper's asynchronous chunk loading. Zero lag, zero main-thread blockages.

YAML Menus & Custom Slots

Create completely custom layouts, shapes, page slots, and action buttons. Decide exactly which slots display homes.

Dynamic Permissions

Dynamic configuration allows changing permission nodes in real-time straight from config.yml.

System Requirements

To run AnyHomes, your server must meet the following operational specifications:

Java 21 or newer Minecraft 1.21.x Paper / Purpur API
  • Supported Software: Paper, Purpur, Folia, and Spigot (Paper or newer is highly recommended for asynchronous teleportation).
  • LuckPerms (Soft Dependency): Required if you wish to configure group-based home limits (e.g. VIP groups having 10 homes while default users have 3) using the home-limit meta key.
  • PlaceholderAPI (Soft Dependency): Hook into PlaceholderAPI to use standard server-wide placeholders inside the plugin's menus and messages.

Commands & Permissions

AnyHomes employs a streamlined, flexible command layout. All permission nodes listed below are dynamic and can be customized inside config.yml.

Command Description Default Permission Type
/home [name] Teleport to your home. Defaults to 'home'. Handles standby warmup countdowns. anyhomes.home Player
/sethome [name] Set a home at your current location. Enforces home limits. anyhomes.sethome Player
/delhome Delete a saved home. Open confirmation GUI if enabled. anyhomes.delhome Player
/homes Opens the homes GUI list or prints a text list. Supports pagination and actions. anyhomes.list Player
/homes :[home] Teleport to a player's home, or list their homes if empty (Admin command). anyhomes.admin Admin
/sethomes : Set a home for another player at your location. anyhomes.admin Admin
/delhomes : Delete another player's home. anyhomes.admin Admin
/anyhomes reload Reload all configurations, messages, and menu structures. anyhomes.admin Admin/Console

Placeholders System

The plugin replaces placeholders dynamically inside its menus, lists, and messages.

Custom Local Placeholders

  • <prefix> - The plugin prefix configured in messages.yml.
  • <home> - Display name/identifier of the home.
  • <world> - World name where the home resides.
  • <coords> - Formatted coordinates (x, y, z).
  • <count> - Player's current total saved homes.
  • <max> - Maximum homes player is allowed to create (or ∞ if unlimited).
  • <seconds> - Leftover seconds on cooldowns/warmup bars.
  • <player> - Target player's name.

PlaceholderAPI Integration

All GUI titles, items, lore lines, chat messages, titles, and action bars fully support PlaceholderAPI formatting, enabling placeholders like %player_name%, %vault_eco_balance%, or %essentials_nickname% natively.

Advanced Color System

AnyHomes supports all modern Minecraft color formatting options out-of-the-box. We use an intelligent character scanner to ensure custom hexadecimal gradients do not clash with raw hex formatting codes.

  • MiniMessage Gradients: <gradient:#ff5f6d:#ffc371><bold>Sunset Gradient</bold></gradient>
  • MiniMessage Hex: <#ffffff>Hex White</#ffffff> or simply <#ff0000>Red Text
  • Standard Alternate Codes: Legacy styling like &7Gray Text, &c&lBold Red
  • Standard Legacy Color Characters: Legacy formatting symbols (§7Gray Text)
  • Raw Hex Format: Quick hex codes like #ff0000Red Text

YAML GUI Customization & Pagination

Configure inventories directly in files inside the menus/ folder. Set sizes, materials, custom player head base64 textures, item actions, and pagination rules easily.

By default, homes are set to display inside slots 20, 21, 22, 23, 24. If a player exceeds 5 homes, the plugin automatically creates a new page, enabling pagination actions on the margins (arrows) to browse residences page-by-page.

# Example home slots and item config in homes.yml
rows: 5
home-slots:
  - 20
  - 21
  - 22
  - 23
  - 24
items:
  help:
    slot: 42
    material: COMPASS
    display-name: "<reset><gradient:#ff5f6d:#ffc371><bold>Help & Commands</bold></gradient>"
    action: OPEN_HELP

01

System Requirements

To run AnyHomes, your server must meet these specifications:

Java 21+ Minecraft 1.21.x Paper / Purpur
  • Supported Software: Paper, Purpur, Folia, Spigot (Paper+ recommended for async teleportation).
  • LuckPerms (soft): Required for group-based home limits via the home-limit meta key.
  • PlaceholderAPI (soft): Use server-wide placeholders inside menus and messages.
02

Commands & Permissions

AnyHomes uses a flexible command layout. All permission nodes are dynamic and can be customized inside config.yml.

Command Description Default Permission Type
/home [name] Teleport to your home. Defaults to 'home'. anyhomes.home player
/sethome [name] Set a home at your current location. anyhomes.sethome player
/delhome <name> Delete a saved home with confirmation. anyhomes.delhome player
/homes Open the homes GUI list with pagination. anyhomes.list player
/homes <player>:[home] Teleport to a player's home, or list theirs. anyhomes.admin admin
/sethomes <player>:<home> Set a home for another player at your location. anyhomes.admin admin
/delhomes <player>:<home> Delete another player's home. anyhomes.admin admin
/anyhomes reload Reload configs, messages, and menus. anyhomes.admin admin
03

Placeholder System

AnyHomes dynamically replaces placeholders inside menus, messages, and chat outputs. Both local and PlaceholderAPI placeholders are supported.

Local Placeholders

<prefix> plugin prefix
<home> home name
<world> world name
<coords> x, y, z
<count> homes count
<max> max homes
<seconds> cooldown / warmup
<player> target player

PlaceholderAPI Integration

All GUI titles, item lore, chat messages, titles, and action bars support PlaceholderAPI placeholders like %player_name%, %vault_eco_balance%, or %essentials_nickname%.

04

Advanced Color System

AnyHomes supports all modern Minecraft color formats with an intelligent parser that handles hexadecimal gradients, MiniMessage, and legacy codes.

  • MiniMessage Gradients: <gradient:#00c6ff:#7b2ffc>Bold Gradient</gradient>
  • MiniMessage Hex: <#ffffff>White Text</#ffffff>
  • Legacy Codes: &7Gray · &c&lBold Red
  • Raw Hex: #ff0000Red Text
05

YAML GUI & Pagination

Customize inventories directly in the menus/ folder. Set rows, materials, player-head textures, item actions, and pagination rules.

By default, homes occupy slots 20–24. When a player has more than 5 homes, the plugin automatically paginates, with arrow controls to browse pages.

# Example from homes.yml
rows: 5
home-slots:
  - 20
  - 21
  - 22
  - 23
  - 24
items:
  help:
    slot: 42
    material: COMPASS
    display-name: "<gradient:#00c6ff:#7b2ffc>Help & Commands</gradient>"
    action: OPEN_HELP

The pagination system automatically adjusts page counts, and you can define custom navigation items (e.g. PREV_PAGE, NEXT_PAGE) in the same menu file.
